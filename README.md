# Capas Meta

Gera a capa da proposta (satélite + perímetro amarelo) a partir do KML/KMZ.

1. Coloque o arquivo em `entrada/` (KML, KMZ, GeoJSON ou shapefile em .zip).
2. A automação gera `saida/<nome>/capa.png` (perímetro à direita, livre do texto)
   e `saida/<nome>/escopo.png` (centralizado), em 2560×1440, além de versões .jpg 1280×720.

Imagem de fundo: Esri World Imagery.
